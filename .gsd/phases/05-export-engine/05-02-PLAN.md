<task type="auto">
  <name>Production ATS Print & PDF Engine with Dedicated @media print Styles & Export Service</name>
  <files>
    client/src/index.css
    client/src/services/exportService.ts
    client/src/components/ResumeStudio.tsx
  </files>
  <action>
    1. Update `client/src/index.css` with production `@media print` rules:
       - Set `@page { size: letter portrait; margin: 0; }`
       - Ensure exact color rendering: `-webkit-print-color-adjust: exact !important; print-color-adjust: exact !important;`
       - Hide non-printable app UI: `header`, `aside`, `.no-print`, `button`, toolbar containers, overflow diagnostic alert banners, cutoff lines, zoom controls, and modals:
         `@media print { body { background: #ffffff !important; color: #000000 !important; } .no-print, header, aside, .print-hidden { display: none !important; } #resume-print-area { position: absolute; left: 0; top: 0; width: 8.5in !important; min-height: 11in !important; margin: 0 !important; padding: 0 !important; box-shadow: none !important; transform: none !important; } }`
       - Apply page break rules to prevent awkward bullet splits:
         `section, .resume-section, .experience-item, .project-item { page-break-inside: avoid; break-inside: avoid; }`
    2. Create `client/src/services/exportService.ts`:
       - `downloadDocxBlob(blob: Blob, filename: string)`: creates temporary URL anchor and triggers browser download.
       - `exportDocx(resumeData: RenderableResume, filename?: string)`: calls `POST /api/export/docx`, receives blob, and invokes download.
       - `triggerPdfPrint(suggestedFilename: string)`:
         - Temporarily sets `document.title = suggestedFilename` (so default browser Save-As PDF filename is formatted cleanly like `Pushpit_Virmani_Resume_Google.pdf`).
         - Dispatches `window.print()`.
         - Resets `document.title` on print window close.
       - Helper `generateExportFilename(candidateName: string, company?: string, role?: string, ext: 'pdf' | 'docx' = 'pdf')`: returns sanitized filename (e.g. `Pushpit_Virmani_Resume_Google_Staff_PM.pdf`).
    3. Enhance `ResumeStudio.tsx`:
       - Wrap the resume container in id `resume-print-area`.
       - Replace the single `window.print()` button with a dual-format export button group:
         - "Download DOCX" button (Word icon, initiates `exportDocx` with active resume data and chosen styling options).
         - "Export PDF" button (PDF icon, initiates `triggerPdfPrint`).
       - Add loading indicator while DOCX is packaging from the backend.
    
    AVOID: Relying on rasterized canvas screenshots (which make PDF text unsearchable for ATS parsers).
    USE: Native vector print engine via `@media print` that produces 100% searchable, selectable text with exact typography and margins.
  </action>

    npm --prefix client run build
  </verify>
  <done>
    `npm --prefix client run build` succeeds without TypeScript or bundling errors, and `client/src/index.css` contains valid `@media print` stylesheet rules.
  </done>
