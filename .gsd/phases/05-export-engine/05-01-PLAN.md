# Plan 05.01: DOCX Generator Engine & Backend Export API

<objective>
Implement a high-fidelity, ATS-compliant DOCX generator service using the `docx` library, and create backend REST export endpoints (`/api/export/docx` and `/api/export/batch`) to support single resume downloads and multi-job batch zip packaging.

Purpose: Top tech ATS systems (Workday, Taleo, Greenhouse, Lever) consistently accept .docx formats. Candidates targeting FAANG and top AI startups need clean, single-column Word documents matching their tailored resumes, preserving word-level bolding metrics and clean section layouts without formatting corruption.
Output: `docxGenerator.ts` service, `export.ts` route mounted on `/api/export`, and automated test suite verifying file integrity and zip bundling.
</objective>

  <files>

  </files>
  <action>
    1. Install `docx` and `archiver` with TypeScript types:
       `npm --prefix server install docx archiver`
       `npm --prefix server install --save-dev @types/archiver`
    2. Create `server/src/services/docxGenerator.ts`:
       - Define input interface accepting candidate contact details (name, email, phone, location, linkedinUrl, portfolioUrl), summary, experience items, project items, skills categories, education items, certifications, and optional styling options (fontFamily: Calibri | Arial | Georgia | Times New Roman, accentColor, fontSize).
       - Page Setup: Standard Letter size (8.5in x 11in) with standard ATS margins (720 to 1080 twips / 0.5 to 0.75in).
       - Single-Column ATS Layout: Strictly avoid floating text boxes, multi-column frames, or decorative graphical shapes that break ATS parsers.
       - Header Section:
         - Candidate Name: 22pt bold, centered or left-aligned depending on template preference.
         - Contact Info: 9.5-10pt text run with clean pipe ` | ` or bullet separators, with clickable hyperlinks for LinkedIn and Portfolio URLs.
       - Section Headings:
         - 11-12pt uppercase bold with letter tracking/spacing.
         - Bottom border line beneath each heading (`border: { bottom: { style: BorderStyle.SINGLE, size: 6, color: accentColor || '0F172A' } }`).
       - Experience & Projects:
         - Job title & Company on line 1 (with dates and location formatted cleanly using right-aligned tab stops or clean inline formatting).
         - Native Word bullet points (`bullet: { level: 0 }`) with tight line spacing (spacing: { before: 40, after: 40, line: 260 }).
       - Word-Level Bolding Parser:
         - Parse `**bold text**` markdown syntax from bullet strings and summary into distinct `TextRun` objects:
           e.g., `"Led **$12M ARR** product launch"` becomes:
           `[new TextRun({ text: "Led " }), new TextRun({ text: "$12M ARR", bold: true }), new TextRun({ text: " product launch" })]`
       - Skills Section:
         - Clean category rows: `Category Name: Skill1, Skill2, Skill3` with Category Name in bold.
       - Export method `generateResumeDocx(resumeData: RenderableResume, options?: DocxOptions): Promise<Buffer>` that uses `Packer.toBuffer(doc)` and returns the resulting Buffer.
    
    AVOID: Complex multi-cell nested tables or shapes; ATS parsers like Workday fail on nested tables.
    USE: Native paragraph tab stops (`TabStopType.RIGHT`), native document bullets, and clean TextRun styling.
  </action>

<task type="auto">
  <name>Create Export REST API Router with Single DOCX & Multi-Job Batch ZIP Endpoints</name>
  <files>
    server/src/routes/export.ts
    server/src/index.ts
  </files>
  <action>
    1. Create `server/src/routes/export.ts`:
       - `POST /api/export/docx`:
         - Accepts JSON body: `{ resume?: RenderableResume, jobId?: string, profileId?: string, templateId?: string, options?: any }`.
         - If `resume` is directly provided: uses it to generate docx.
         - If `jobId` is provided: queries `TailoredResume` for the job (falling back to `MasterResume` if none exists yet), transforms JSON into `RenderableResume`, and generates docx.
         - If `profileId` is provided: queries `MasterResume` for that profile, parses JSON fields, and generates docx.
         - Sets headers:
           - `Content-Type: application/vnd.openxmlformats-officedocument.wordprocessingml.document`
           - `Content-Disposition: attachment; filename="${sanitizedFilename}.docx"`
         - Sends the DOCX buffer.
       - `POST /api/export/batch`:
         - Accepts JSON body: `{ jobIds: string[], profileId?: string, format?: 'docx' | 'pdf' | 'all', templateId?: string }`.
         - Validates `jobIds` is a non-empty array (max 50 jobs per batch).
         - Fetches each Job record and its corresponding `TailoredResume` (or master profile).
         - Instantiates `archiver('zip', { zlib: { level: 9 } })`.
         - Sets response headers:
           - `Content-Type: application/zip`
           - `Content-Disposition: attachment; filename="tailored_resumes_batch_${Date.now()}.zip"`
         - Pipes zip archive to `res`.
         - For each job:
           - Builds `RenderableResume`.
           - Generates DOCX buffer using `generateResumeDocx`.
           - Formats clean filename: `${CandidateName}_Resume_${CleanCompany}_${CleanRole}.docx`.
           - Appends buffer to archive: `archive.append(buffer, { name: filename })`.
         - Finalizes the archive with `await archive.finalize()`.
    2. Mount the router in `server/src/index.ts`:
       `import exportRouter from './routes/export.js';`
       `app.use('/api/export', exportRouter);`
    
    AVOID: Holding entire zip in unbuffered memory for massive batches; pipe the archiver stream directly to `res`.
    USE: Proper error handling if archiver encounters an error, and sanitize filenames to remove special characters (`/`, `\`, `:`, `*`, `?`, `"`, `<`, `>`, `|`).
  </action>
  <verify>
    npx tsx -e "import app from './server/src/index.js'; const server = app.listen(5099, async () => { try { const res = await fetch('http://localhost:5099/api/export/docx', { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ resume: { name: 'Test PM', email: 'test@example.com', summary: 'Summary', experience: [], skills: [], education: [] } }) }); const ct = res.headers.get('content-type'); const cd = res.headers.get('content-disposition'); const buf = await res.arrayBuffer(); console.log('STATUS:', res.status, 'CT:', ct, 'BYTES:', buf.byteLength); server.close(); if (res.status === 200 && ct.includes('openxmlformats') && buf.byteLength > 500) process.exit(0); else process.exit(1); } catch (e) { console.error(e); server.close(); process.exit(1); } });"
  </verify>
  <done>
    `POST /api/export/docx` returns 200 with `application/vnd.openxmlformats-officedocument.wordprocessingml.document` and a valid binary document.
  </done>
</task>
